| 과목 | 자료 | 상태 |

| 파이썬프로그래밍기초 | PDF 15강 + 강의체크포인트(46p) | 신규 |

### 저작권 방침
- 슬라이드 원문을 통째로 옮기지 않는다. 개념을 **요약·재구성·쉬운 말로 재서술**한다.
- 기출 문제는 **원문 전재 금지**. 빈출 주제 분석 + **변형 문항**으로 재작성한다.

## 3. 사이트 구조 (IA)

```
/                       허브: 과목 카드 3개, 공통 헤더
/html-css/              기존 페이지 이동 (콘텐츠 무변경, 네비만 허브 연결)
/computer/              컴퓨터의이해
/python/                파이썬프로그래밍기초
/assets/
  ├─ base.css           공용 디자인 시스템 (기존 styles.css에서 추출)
  └─ quiz-engine.js     공용 퀴즈 엔진 (문항 데이터 주입형)
```

- URL `raccooncoon.github.io/html5-101/` 유지. 루트가 허브가 되므로 기존 북마크 사용자는 허브에서 1클릭으로 HTML 과목 진입.
- 과목별 액센트 컬러: HTML=주황(기존), 컴퓨터의이해=틸, 파이썬=블루.

## 4. 과목 페이지 설계

### 공통 패턴 (기존 검증 구조 재사용)
- sticky 목차 · 읽기 진행률 바 · 다크/라이트 토글 · 맨위로 버튼
- 강의별 섹션: 쉬운 설명(lead-easy) + 비유 + 시각 자료(표/카드/플로우)
- ⭐ 시험 정리: 무조건 외울 규칙 표 / 헷갈리는 짝 비교 / 함정 모음
- 📝 퀴즈: quiz-engine.js + 과목별 문항 데이터(채점·해설·점수)

### 컴퓨터의이해 특화
- 15강을 5개 파트로 묶어 목차 구성:
  ① 컴퓨터와 정보사회(1~3강) ② 하드웨어(4~5강) ③ 소프트웨어와 데이터(6~7강)
  ④ 네트워크·인터넷·보안(8~12강) ⑤ 멀티미디어와 미래 기술(13~15강)
- **체험형 도구**:
  1. 진법 변환기 — 2/8/10/16진수 상호 변환, 변환 과정 표시(시험 단골)
  2. 논리 게이트 시뮬레이터 — AND/OR/NOT/XOR 입력 토글 → 출력 즉시 확인
  3. (여유 시) 보수 계산기 — 1의 보수/2의 보수 단계별 표시
- **기출 분석 섹션**: 3개년 105문항을 시각 판독 → 주제 태깅 → 빈출 주제 TOP 정리표 → 변형 문항 30개 이상 퀴즈화

### 파이썬프로그래밍기초 특화
- 모든 예제 코드는 실행 가능한 스니펫으로 작성, 각 코드 블록에 **"▶ 실행" 버튼**
- **Pyodide 실행기**: CDN 지연 로드(첫 실행 클릭 시 다운로드, 로딩 안내 표시), stdout 캡처·에러 표시, 코드 수정 후 재실행 가능
- 페이지 하단에 자유 입력 **파이썬 놀이터**(HTML 코드 놀이터와 동일한 UX)
- 체크포인트 46문항 → 주제별 분류 후 강별 확인문제 + 종합 퀴즈로 재구성

## 5. 콘텐츠 제작 파이프라인

1. **추출**: `pdftotext -layout`(텍스트) + `pdftoppm -png`(기출 전체·파이썬 그림 페이지)
2. **정리**: 병렬 서브에이전트로 강별 핵심 개념 구조화 — 과목당 3개 에이전트(5강씩), 산출물은 강별 핵심개념·용어·예제·시험포인트 구조화 텍스트
3. **본문 작성**: 구조화 자료 기반으로 페이지 직접 작성(기존 톤 유지 — 쉬운 말, 비유, 표)
4. **기출/체크포인트**: 페이지 이미지 시각 판독 → 문항·주제 추출 → 빈출 분석표 + 변형 문항 작성
5. **검증**: 로컬 프리뷰 — 콘솔 에러 0, 도구·실행기·퀴즈 동작 확인, 반응형(≤860px) 확인
6. **배포**: 커밋 → push → GitHub Actions → 라이브 콘텐츠 확인 (기존 워크플로 그대로)

## 7. 기술 결정

- 빌드 없는 정적 HTML/CSS/JS 유지(현행과 동일, GitHub Pages 직배포)
- Pyodide v0.26+ jsDelivr CDN, 메인스레드 실행(교육용 짧은 코드 전제), 첫 클릭 시 로드
- 퀴즈 엔진: 기존 script.js의 퀴즈 로직 분리 → `assets/quiz-engine.js`(문항 배열 주입)
- 디자인: 기존 CSS 변수 시스템 확장(`--accent` 과목별 오버라이드)
- 라이브 데모 iframe 패턴(HTML 과목)은 컴퓨터의이해·파이썬에서는 불필요 — 도구/실행기로 대체
