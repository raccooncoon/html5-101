01

HTML 문서 구조와 텍스트 표현

기본 문서 템플릿

<!DOCTYPE html>로 시작해 표준 모드 렌더링을 보장합니다. <html>에는 스크린 리더·검색엔진을 위해 lang="ko"를 필수로 넣습니다. <head>에는 메타데이터(charset, viewport)와 CSS/JS 링크가, 실제 화면 내용은 <body>에 들어갑니다.

<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>문서 제목</title>
  </head>
  <body><!-- 보이는 내용 --></body>
</html>

텍스트 마크업 규칙

  • 헤딩 h1~h6: 문서 구조·목차를 만듭니다. h1은 페이지당 1개, 숫자를 건너뛰지 않고 순차 사용. 폰트 크기 키우려고 쓰면 안 됩니다 — 크기는 CSS로.
  • 단락·줄바꿈: 단락은 <p>, 문단 여백은 CSS로. <br> 연타로 여백 만들기 금지. 주소·시처럼 줄바꿈이 의미일 때만 <br>.
  • 물리적 vs 논리적: <b>보다 의미 강조 <strong>, <i>보다 <em>가 접근성 표준.
블록 vs 인라인 — 한 줄을 다 차지하는 블록(div, p, h1) vs 내용만큼만 차지하는 인라인(span, a, img). 의미 없는 div 남용은 피하세요.
02

리스트, 이미지, 링크, 테이블

리스트

순서 없는 <ul>, 순서 있는 <ol>(start, type 활용). '키:값'/용어-설명 구조는 <dl><dt><dd> 세트로 — 스크린 리더 이해도가 올라갑니다.

<dl>
  <dt>프로세서</dt><dd>인텔 Core i7</dd>
  <dt>메모리</dt><dd>16GB</dd>
</dl>

이미지 · 링크

  • 이미지: src와 함께 alt 필수. 장식용이면 alt=""로 비워 리더기가 무시하게 합니다.
  • 링크: target="_blank"로 새 창 열 땐 보안상 rel="noopener noreferrer"를 함께. 페이지 내 이동은 목적지에 id, <a href="#아이디">로 연결.

테이블

표 형태 데이터에만 사용(레이아웃용 금지). 접근성을 위해 th에 scope="col"/"row", 병합은 colspan(가로)·rowspan(세로).

미디어

04

웹 폼과 입력 요소

데이터 통신 본부 <form>: action(전송 주소), method(GET/POST)로 서버와 연결합니다.

  • 입력 타입: text·password·number·date·file·checkbox·radio 등 데이터 종류에 맞게 — 모바일에서 알맞은 키보드가 뜹니다. (checkbox=다중, radio=단일)
  • 긴 글 <textarea>, 드롭다운 <select>+<option>.
  • 접근성 핵심 <label>: for와 id를 일치시켜 글씨 클릭으로도 입력창이 활성화 — 클릭 영역 확대 + 리더 지원.
  • fieldset+legend: 라디오/체크박스 묶음을 박스로 묶고 그룹 제목을 달아 맥락 전달.
<label for="email">이메일</label>
<input id="email" type="email" required>
05

CSS 선택자와 우선순위

설계 원칙: 포괄적 요소명(p)이나 재사용 어려운 #id보다 .class 중심 모듈화가 유지보수에 유리합니다.

명시도(우선순위) 점수

우선대상점수

2인라인 스타일1000
3#id100

결합자 & 가상 클래스

  • A > B 직계 자식 · A B 모든 자손 · A + B 바로 뒤 형제 · A ~ B 뒤 모든 형제
  • :hover 마우스 오버 · :focus-visible 탭 키 이동 시만 테두리 · :required 필수 입력창
06

CSS 텍스트 최적화

한국어 가독성 세팅

  • line-height는 상속 꼬임 방지를 위해 단위 없는 숫자(1.5~1.6)로.
  • word-break: keep-all; 한글 단어 중간 줄바꿈 방지 + overflow-wrap: break-word; 긴 영어/URL 박스 탈출 방지.

말줄임표(…) 공식

.ellipsis {
  white-space: nowrap;     /* 한 줄 고정 */
  overflow: hidden;        /* 넘침 숨김 */
  text-overflow: ellipsis; /* … 표시 */
}
text-wrap: balance; — 여러 줄 제목이 균형 있게 줄바꿈되도록 자동 조절.
07

배경, 박스 모델, 레이아웃(position)

배경 · 모서리 · 그림자

  • 가독성용으로 linear-gradient 반투명 막 + 그 아래 url() 이미지를 겹치는 기법. background-size: cover;는 빈틈없이 꽉 채움.
  • border-radius: 50% 완벽한 원, box-shadow 입체감. outline은 물리적 크기를 차지하지 않는 외곽선(접근성용).

position

값동작
relative원래 자리 유지하며 이동. absolute 자식의 기준 뼈대
absolute떠서 가장 가까운 relative 부모 기준 배치(예: '품절' 배지)
fixed / sticky스크롤해도 화면에 고정되는 헤더·메뉴
08

Flexbox & Grid

Flex — 1차원

가로 또는 세로 한 방향 배치. justify-content(주축 정렬), align-items(교차축 정렬).

123
display: flex;
justify-content: space-between;
align-items: center;

Grid — 2차원

행·열 동시 배치. grid-template-areas로 구역에 이름을 붙여 직관적으로 뼈대 설계.

header main aside footer
09

애니메이션 & 다단 레이아웃

  • transform: translate(이동)·rotate(회전)·scale(크기). 최근엔 각각 독립 속성으로 분리.
  • transition: :hover 시 부드러운 변화 — transition: 속성 시간 타이밍함수(ease).
  • @keyframes: 0%→100% 세밀한 시나리오, 무한 반복·복잡한 모션.
  • 다단(Multi-column): column-count·column-width로 긴 글을 여러 단으로. 카드가 단 경계에서 잘리는 것은 자식에 break-inside: avoid;로 방지.
이 박스에 마우스를 올려보세요 (transition + transform)

시험에 나올만한 것 — 핵심 정리

출제 빈도가 높은 포인트를 "함정 위주"로 모았습니다. 시험 직전 이 표만 복습해도 됩니다.

① 반드시 외울 규칙

주제정답 포인트
h1 개수페이지당 1개, 숫자 건너뛰기 금지
main 개수문서에 단 하나
이미지 alt필수. 장식용은 alt=""
새 창 링크target="_blank" + rel="noopener noreferrer"
label 연결for ↔ id 일치
line-height단위 없는 숫자(1.5)
th 접근성scope="col"/"row"
병합가로 colspan / 세로 rowspan

② 명시도 순서 (단골 출제)

!important > 인라인(1000) > #id(100) > .class·가상클래스(10) > 태그(1) > *(0)

③ 헷갈리는 짝 비교

strong vs b

strong=의미상 강조(접근성), b=단순 굵게

em vs i

em=의미상 강조, i=단순 기울임

Flex vs Grid

Flex=1차원(한 방향), Grid=2차원(행+열)

relative vs absolute

relative=자리 유지·기준점, absolute=relative 부모 기준 띄움

section vs article

section=주제 구역, article=독립 배포 가능한 완결 글

> vs (공백)

>=직계 자식만, 공백=모든 자손

④ 자주 틀리는 함정

  • 헤딩을 폰트 크기 용도로 쓰기 → 금지(크기는 CSS)
  • <br> 연타로 여백 만들기 → 금지(여백은 CSS)
  • 테이블을 레이아웃용으로 사용 → 금지(데이터 전용)
  • 말줄임표 3종 세트 누락 → nowrap + overflow:hidden + text-overflow:ellipsis 모두 필요
  • line-height: 24px처럼 단위 붙이기 → 상속 꼬임
  • 다단에서 카드 잘림 → break-inside: avoid; 누락
