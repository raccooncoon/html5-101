①

컴퓨터와 정보사회 (1~3강)

1강 · 정보사회와 컴퓨터

19세기엔 증기기관이 세상을 바꿨고(산업혁명), 20세기엔 컴퓨터·통신이 세상을 바꿨습니다(정보혁명). 2016년 클라우스 슈밥이 말한 4차 산업혁명은 AI·IoT·빅데이터가 주인공이에요.

1차 증기기관 2차 전기 3차 컴퓨터 4차 AI·IoT·빅데이터
  • 데이터 vs 정보 — 데이터는 가공 전 원재료(성적 점수 입력), 정보는 의미 있게 가공된 결과(성적표). "데이터 → 처리 → 정보" 순서만 기억하세요.
  • 컴퓨터시스템 구성 — 하드웨어 5요소: 입력장치·기억장치·연산장치(ALU)·제어장치·출력장치. 소프트웨어는 사람과 하드웨어 사이의 매개체.
  • 이동통신 세대 — 1G 아날로그 음성 → 2G 음성+문자(CDMA) → 3G +영상·인터넷 → 4G LTE(100Mbps~1Gbps) → 5G 20Gbps(4G의 20배, 초저지연·초연결).
  • 유비쿼터스 — 라틴어 "도처에 존재한다". 1988년 마크 와이저(Mark Weiser)가 제시. 3A(Anytime·Anywhere·Anydevice) + 5C(Computing·Communication·Connectivity·Contents·Calm).
컴퓨터 종류 크기순 — 개인용 PC(1974 MITS 키트가 최초) < 서버 < 메인프레임(1950년대, 대기업 중앙 컴퓨터) < 슈퍼컴퓨터(우주·일기예보·국방). 특수 목적엔 전용컴퓨터(미사일 유도, 가전 내장).

2강 · 컴퓨터와 통신산업의 발전

컴퓨터 역사는 "무엇으로 회로를 만들었나"로 세대를 나눕니다. 진공관 → 트랜지스터 → 집적회로(IC) → 고밀도 IC. 이 순서가 시험의 단골입니다.

세대시기핵심 소자대표 컴퓨터·사건
1세대1946~1957진공관ENIAC(1946, 진공관 18,000개·30톤), EDVAC(폰 노이만 프로그램 내장), UNIVAC I(1951)
2세대1958~1964트랜지스터(1947 벨연구소)TRADIC(1954), 고급언어 FORTRAN·COBOL 등장, 자기코어 메모리
3세대1965~1971집적회로(IC)IBM 시스템/360(1964), 운영체제·다중프로그래밍, 미니컴퓨터(1965 DEC)
4세대1972~현재고밀도 IC(LSI→VLSI→ULSI)마이크로프로세서(1971 Intel 4004), PC·서버·인터넷
  • 컴퓨터 이전의 계산도구 — 파스칼 가산기(1642) → 라이프니츠 승제산기(1674) → 배비지 해석기계(1834): 입력·출력·기억·제어·계산, 현대 컴퓨터 5대 기능의 원형(당시 기술로 제작 불가).
  • 최초 논쟁 정리 — 최초의 전자식 디지털 컴퓨터는 ABC(1937~42, 아타나소프·베리, 1973년 특허 인정). 최초의 "대형" 전자식은 ENIAC(1946).
  • 마이크로프로세서 — 연산장치+제어장치를 칩 하나에 집적(1971 Intel 4004, 3×4mm인데 ENIAC의 10배 성능). 이게 PC 시대를 열었습니다(Apple 1977, IBM PC).

3강 · 처리장치와 데이터 처리

CPU는 컴퓨터의 두뇌. 그 안에 계산 담당(ALU), 지휘 담당(제어장치), 메모지(레지스터)가 들어 있습니다.

ALU

산술(가감승제) + 논리(비교·Shift) 연산 수행

제어장치

시스템 전체 지시·감독·조정, 입출력 제어

레지스터

처리할 명령어·데이터를 잠시 보관하는 초고속 저장소

  • 비트와 바이트 — 비트(bit)는 0/1 한 자리(전류 ON/OFF), 8비트 = 1바이트 = 영문 1글자.
  • 용량 단위(2의 거듭제곱) — KB(2¹⁰) → MB(2²⁰) → GB(2³⁰) → TB(2⁴⁰) → PB(2⁵⁰). 속도 단위는 ms(10⁻³) → µs(10⁻⁶) → ns(10⁻⁹) → ps(10⁻¹²).
  • 진법 — 컴퓨터는 2진법으로 저장합니다. (1010)₂ = 8+2 = 10. 16진법은 10~15를 A~F로 표기. 아래 변환기에서 직접 돌려보세요.
  • 문자 인코딩 — ASCII는 7비트(128문자, '0'=30 'A'=41 'Z'=5A in 16진), 유니코드는 16비트(1991년, 65,536문자)로 한글·한자 등 전 세계 문자 표현.
  • 데이터 계층 — 필드(최소 단위: 이름·주소) → 레코드(필드 모임: 한 사람 정보) → 파일(레코드 모임).
헷갈리면 시험에서 틀리는 메모리 — SRAM=캐시용(빠름, 리프레시 불필요) vs DRAM=주기억장치용(리프레싱 필요). ROM=읽기 전용(제작 시 기록) vs RAM=읽고 쓰기. 자기코어(1950s)는 비휘발성인데 느리고, 반도체는 빠른데 휘발성!
②

하드웨어 — 입출력과 저장장치 (4~5강)

4강 · 컴퓨터의 입출력

처리 방식엔 두 갈래가 있어요. 일괄처리는 모아서 한 방에(OMR 채점, 효율 중시), 대화식 처리는 입력 즉시 응답(웹 검색·뱅킹, 응답속도 중시).

  • 입력 3분류 — ① 단말기 입력(키보드·마우스·터치·음성) ② 원시 데이터 직접 입력(OMR·OCR·MICR·바코드) ③ 보조기억매체(디스크·USB).
  • 원시문서 4형제 — OMR 마크 인식(시험 답안지) / OCR 글자 인식(인쇄·손글씨) / MICR 자기잉크 글자(은행 수표, E-13B 서체) / 바코드 흑백 막대(상품). +2차원 QR코드(1994 덴소 웨이브, 최대 2,953바이트), RFID(IC칩+전자기장 무선 인식).
  • 데이터 검증 5단계 — 문자종류 확인 → 타당성 → 범위 → 일관성 → 체크디지트(오류 검출용 추가 숫자. 입력 후 재계산해 비교). "GIGO: 쓰레기를 넣으면 쓰레기가 나온다"가 검증의 이유.
  • 해상도 — HD(1280×720) < Full HD(1920×1080) < QHD(2560×1440) < 4K UHD(3840×2160) < 8K(7680×4320).
  • 프린터 — 충격식(도트 매트릭스·데이지 휠) vs 비충격식(레이저·잉크젯·감열). 3D 프린터는 절삭형(깎기) vs 적층형(쌓기).

5강 · 보조기억장치와 데이터 저장

주기억장치(RAM)는 좁고 전원이 꺼지면 다 잊어버립니다. 그래서 크고(대용량) 안 잊는(비휘발성) 보조기억장치가 필요해요. 핵심 구분은 순차접근 vs 직접접근.

접근매체핵심 포인트
순차자기테이프(DAT·DLT·LTO)처음부터 차례로 읽음 → 느림 → 백업 전용. LTO-9는 18TB(압축 45TB)
직접하드디스크트랙(원) → 섹터(조각) → 실린더(같은 반경 트랙 묶음). 성능 = 탐색시간+회전지연+전송시간
광디스크CD(700MB) → DVD(4.7/8.5GB) → Blu-ray(25/50/128GB). 기록방식: ROM(읽기만)·WORM(1회 기록)·RW(약 1,000회)
SSD·플래시무동작 부품 → 빠르고 튼튼·저전력. 단점: 쓰기 수명 한정, 고가

CLV vs CAV

CLV=일정한 선속도, 나선형 트랙(광디스크) / CAV=일정한 각속도, 동심원(자기디스크, 직접접근 빠름)

SLC vs MLC

SLC=셀당 1비트(안정·빠름·비쌈) / MLC·TLC·QLC=셀당 2~4비트(저렴하지만 느리고 수명↓)

RAID

여러 디스크에 분산 저장해 신뢰성·성능 향상(디스크 어레이)

클라우드 저장

인터넷 기반, 쓴 만큼 지불. Google Drive·OneDrive·DropBox·iCloud

USB 속도 — USB 2.0은 최대 480Mbps, USB 3.2는 최대 20Gbps. 기억장치 계층은 "레지스터 → 캐시 → 주기억 → 보조기억"(위로 갈수록 빠르고 작음).
③

소프트웨어와 데이터 (6~7강)

6강 · 소프트웨어의 종류

소프트웨어는 딱 두 부류입니다. 컴퓨터 자체를 돌리는 시스템 소프트웨어(OS·컴파일러·유틸리티)와, 특정 일을 하는 응용 소프트웨어(워드·엑셀·포토샵).

  • 운영체제의 4가지 역할 — ① 사용자 인터페이스 제공(CLI/GUI) ② 하드웨어 장치 관리 ③ 파일시스템 관리 ④ 프로그램 실행 관리.
  • 부팅 순서 — ROM의 BIOS 실행 → POST(자가진단) → Booting(OS를 RAM에 적재). 시험에 순서로 나옵니다.
  • OS 연표 — UNIX(1970년대 벨연구소, 멀티유저) / Linux(1991 리누스 토발즈, 오픈소스) / Windows 10(2015)·11(2021) / Mac OS X(2001).
  • 컴파일러 vs 인터프리터 — 컴파일러는 전체를 한 번에 번역(실행 빠름), 인터프리터는 한 줄씩 해석·즉시 실행(결과 확인 빠름).
  • 프로그래밍 언어 세대 — 1GL 기계어 → 2GL 어셈블리 → 3GL 고급언어(C·Java) → 4GL 특정응용(DB질의) → 5GL 인공지능(LISP·Prolog).
사용권비용특징
정품 소프트웨어유료허가 범위 내 사용, 수정·공유 제한
셰어웨어체험 무료판매 목적이지만 기간·기능 제한판 무료 제공
프리웨어무료개인 사용만 무료 — 직장 사용은 저작권 침해 소지
자유 소프트웨어무료사용·분석/수정·재배포·수정본 배포의 4가지 자유(GPL). 1983 스톨먼 GNU

기업 정보시스템 약어 — TPS(거래처리) · DSS(의사결정지원) · ERP(전사적 자원관리: 생산~회계 통합) · CRM(고객관계) · SCM(공급망).

7강 · 데이터베이스

파일로 따로따로 관리하면 같은 데이터가 여기저기 중복되고 서로 어긋납니다. 그래서 데이터를 한 곳에 모으고 DBMS라는 관리인을 통해서만 접근하게 만든 것이 데이터베이스입니다.

  • DBMS의 3대 기능 — ① 구조 정의(논리적·물리적 구조) ② 데이터 조작(검색·삽입·수정·삭제) ③ 데이터 제어(무결성·권한·병행제어).
  • 데이터베이스 언어 — DDL(정의: 스키마 생성·변경·삭제) / DML(조작: 삽입·검색·수정·삭제). 표준 언어는 SQL.
  • 데이터 접근 3구조 — 순차적(처음부터 훑기) / 상대적·직접적(Key→주소 변환) / 인덱스(색인으로 위치 찾기, 검색 최速).

네트워크 · 인터넷 · 보안 (8~12강)

8강 · 정보통신기술과 우리 사회

ICT는 정보를 주고받는 기술(IT의 확장). 특징은 시공간 극복 + 다양한 형태 전달 + 타 기술과 융합. 분야별 사례 한 개씩만 연결해두면 됩니다.

경제

핀테크(금융+IT), 물류 드론

교육

e-Learning(언제 어디서나 맞춤형), OLPC 100달러 노트북

의료

e-Health/u-Health 원격 의료, 웨어러블

스포츠

2014 독일 빅데이터 우승, 2018 골라인 판독(IoT)

정치

2012 오바마 캠프 빅데이터(AWS)

과학

우주 인터넷(DTN), 자율주행, 지능형 로봇

9강 · 4차 산업혁명과 미래사회

4차 산업혁명(Industry 4.0, 2016 슈밥)의 특징 3가지: 속도(기하급수적)·범위(전 분야)·시스템 영향(물리·디지털·생물 융합). 핵심 기술 4가지가 한 세트로 움직입니다.

IoT가 수집 클라우드가 저장 빅데이터가 분석 AI가 판단
  • 빅데이터 5V — Volume(규모)·Velocity(속도)·Variety(다양성)·Value(가치)·Veracity(신뢰성).
  • 클라우드 서비스 3층 — SaaS(소프트웨어: Office 365) / PaaS(개발 플랫폼) / IaaS(서버·인프라). 장점: 초기비용↓·종량제·어느 기기서나·안전 보관. 단점: 유출 우려·통신환경 의존.
  • AI 기술 묶음 — 머신러닝(데이터로 학습) ⊃ 딥러닝(신경망 모방), 자연어 처리(NLP), 컴퓨터 비전.

10강 · 정보통신

통신의 역사는 연도 암기가 핵심: 1837 모스 전신 → 1876 벨 전화기 → 1958 SAGE(최초 컴퓨터통신) → 1964 SABRE(좌석예약) → 1969 ARPANET(인터넷 전신).

  • 통신망의 3가지 목적 — 자원 공유 · 신뢰도 향상(대체 경로) · 처리기능 분산.
  • 연결장치 역할 구분 — Modem(디지털↔아날로그 변환) / Hub(다포트 중계) / Repeater(신호 증폭) / Bridge(같은 프로토콜 연결) / Router(IP로 경로 결정) / Gateway(다른 프로토콜 변환).
  • 전송 방향 — 단방향 Simplex(TV) / 반이중 Half-Duplex(무전기: 양방향이지만 동시에 X) / 전이중 Full-Duplex(전화: 동시 O).
  • 네트워크 위상 5형 — 성형(중앙 집중, 중앙 고장 시 전체 마비) / 환형(원형) / 버스형(일직선) / 그물형(다중 경로, 신뢰도 최고·비용 최고) / 트리형(계층).
  • 규모순 — PAN(개인, 블루투스) ⊂ LAN(건물) ⊂ CAN(캠퍼스) ⊂ MAN(도시) ⊂ WAN(광역·인터넷).
교환방식원리특징
회선교환전용 회선을 먼저 연결지연·대역폭 일정, 효율 낮음 — 전화
메시지교환중간 노드에 통째로 저장 후 전달(축적교환)지연 가변, 손실 가능 — 과거 기술
패킷교환작은 패킷으로 쪼개 전송효율 최고, 인터넷의 기반. TCP(연결형·순서 보장)/UDP(비연결형)

11강 · 인터넷

인터넷 = INTERconnected NETwork, "네트워크의 네트워크". 기반은 TCP/IP입니다. 1969년 ARPANET에서 출발해 1983년 군용(MILNET)과 민간용으로 분리됐어요.

  • IP 주소 — IPv4는 32비트(약 43억 개, 부족!) → IPv6는 128비트(사실상 무한, 유비쿼터스 대비).
  • DNS — 도메인 이름(www.knou.ac.kr)을 IP 주소(203.232.172.32)로 변환해 주는 시스템.
  • URL 구조 — 프로토콜://도메인/경로/파일명.
  • 서비스와 프로토콜 짝 — 웹=HTTP / 메일 발송=SMTP, 수신=POP3·IMAP / 파일 전송=FTP / 원격 접속=Telnet.
  • 전자상거래 — B2B(기업↔기업) / B2C(기업↔소비자) / C2C(소비자↔소비자, 중고거래).

12강 · 정보보안 — 최다 빈출!

보안의 3대 목표는 CIA: Confidentiality 기밀성(노출 방지) · Integrity 무결성(변조 방지) · Availability 가용성(필요할 때 접근 가능). 모든 보안 문제는 이 셋 중 무엇이 깨졌는지로 분류됩니다.

스니핑 vs 스푸핑

스니핑=도청(엿듣기, 암호화로 방어) / 스푸핑=위조(가짜 IP·사이트로 속이기)

DoS vs DDoS

DoS=서비스 거부 공격 / DDoS=여러 컴퓨터로 분산 공격

피싱 vs 파밍

피싱=가짜 사이트로 유인해 정보 입력 요구 / 파밍=진짜와 똑같은 가짜 사이트(더 위협적)

악성 프로그램감염자기복제특징
바이러스O (정상 파일에 기생)O부팅 지연, 데이터 변조 — 백신으로 방어
웜XO (독립 복제)이메일·메신저로 전파, DDoS에 동원

대칭키(비밀키)암호화 = 복호화빠름어려움불가DES, 3DES
비대칭키(공개키)공개키 ≠ 개인키느림해결가능(전자서명)RSA
전자서명 — 개인키로 서명 → 공개키로 검증. 위변조 방지·부인 방지·인증 보장. 기반 구조는 PKI. 방화벽은 내부망과 외부망을 분리하는 차단벽.

멀티미디어와 미래 기술 (13~15강)

13강 · 멀티미디어

멀티미디어 = 텍스트·그림·소리·영상 중 2가지 이상이 통합된 것. 특징 4가지: 디지털성·무손실성(복제해도 품질 유지)·상호작용성·비선형성(아무 데나 점프 가능).

래스터 vs 벡터

래스터=픽셀 점들(확대하면 깨짐, 사진) / 벡터=수학 도형(확대해도 매끈, 로고)

하이퍼텍스트/미디어

하이퍼텍스트=링크로 연결된 글 / 하이퍼미디어=+오디오·비디오까지

코덱

Coder+Decoder. 비디오는 손실압축: MPEG, H.264(AVC), H.265(HEVC)

이미지 형식압축특징·용도
BMP없음파일 큼, Windows 기본
GIFLZW(무손실)최대 256색, 애니메이션·투명색 지원
PNG무손실GIF 특허 문제 대안, 트루컬러
JPEG손실높은 압축률, 사진용

XR 연속체 — 실제 환경 ↔ AR(현실+디지털 정보) ↔ MR(가상·현실 상호작용) ↔ VR(완전 가상). 이 모두를 포괄하는 말이 XR(확장현실). 메타버스 = Meta(초월)+Universe.

14강 · 유비쿼터스

컴퓨터와 사람의 관계로 4단계를 외우세요: 메인프레임(여럿이 1대) → PC(소수가 1대) → 인터넷(1인 1대) → 유비쿼터스(1인 多대, 컴퓨터가 보이지 않게 스며듦).

  • 마크 와이저의 4가지 기준 — ① 모든 장치 연결(Network) ② 인터페이스는 눈에 안 보이게(Invisible) ③ 어디서나 사용 ④ 생활에 통합.
  • 관련 기술 한 줄씩 — MEMS(초소형 기계·전자 융합) / RFID(무선 인식: 이동 중·원거리 OK, 위조 불가) / USN(센서 네트워크) / 임베디드(기기 내장 컴퓨터: 밥솥·세탁기) / SoC(칩 하나에 시스템 전부).
  • 블루투스 vs 지그비 — 블루투스: 10m 무선 연결. 지그비: 블루투스의 고가·고전력 단점을 보완한 저전력·저비용 근거리 통신.
  • IoT — 1999년 MIT의 Kevin Ashton이 제시. 사물끼리 사람 개입 없이 정보 교환. 응용: 스마트팜·자율주행·헬스케어·스마트홈·스마트시티(국내 시범: 세종·부산).
인물-연도 짝 절대 헷갈리지 말 것 — 유비쿼터스 = Mark Weiser, 1988(제록스 PARC) / IoT = Kevin Ashton, 1999(MIT). 시험에 서로 바꿔서 나옵니다.

15강 · 모바일서비스

모바일 시장의 패러다임: 음성 통화 중심 → OS+앱 중심. 하드웨어 스펙 경쟁에서 소프트웨어 생태계 경쟁으로 넘어왔습니다.

모바일 OS개발특징점유율(2022)
Android구글, 2007 OHA 결성Linux 커널·오픈소스, 자바 개발, Play Store약 71%

KaiOS2017, Firefox OS 기반저사양·경량(200MB), 개도국 피처폰소수
  • 플랫폼 분류 — 공개형(API 제공: iOS·Symbian) vs 공개소스형(소스 공개: Android).
  • WIPI — 한국형 무선인터넷 플랫폼. 2005~2009년 국내 휴대폰 의무 탑재.
  • 웨어러블 — 안경·시계·의복형 컴퓨터. 신체에 가장 가깝고 스마트폰과 무선 연동(갤럭시 워치).

④ 자주 틀리는 함정 포인트

  • 정보보안 3요소에 "접근성"은 없다 — 기밀성·무결성·가용성(CIA). '접근성'이 보기에 나오면 함정.
  • CPU는 저장하지 않는다 — '프로그램 영구 저장'이 CPU 기능으로 나오면 오답.
  • 통신망 목적에 '중앙집중형 처리'는 반대말 — 목적은 분산.
  • 백신은 해킹 '방법'이 아니라 방어 수단.
  • BMP가 압축률 높다? — 반대. BMP는 무압축이라 가장 크다.
  • HDMI는 인터넷 프로토콜이 아니다(영상 인터페이스).
  • 트로이목마는 자기복제를 못 한다 — 복제하는 건 바이러스·웜.
