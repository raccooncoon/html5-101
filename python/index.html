①

컴퓨터와 파이썬 시작 (1~3강)

1강 · 컴퓨터의 이해 — 프로그래밍 전에 알아둘 것

데이터는 관찰·측정의 원재료(불꽃 색, 온도 3500도), 정보는 그걸 정제·해석한 결과(파란 불꽃이 더 뜨겁다). 컴퓨터는 "데이터를 자동으로 처리해 정보를 만드는 기계"입니다.

  • 비트와 바이트 — 컴퓨터는 모든 것을 0/1(비트)로 저장. 8비트 = 1바이트.
  • 폰 노이만 구조 — 입력장치 → (제어·연산: CPU) ↔ 기억장치 → 출력장치.
  • RAM vs HDD/SSD — 주기억장치(RAM)는 빠르지만 휘발성, 보조기억장치는 느리지만 보존됨. 12강 '파일'이 중요한 이유!

2강 · 파이썬의 이해

파이썬은 1991년 귀도 판 로섬(Guido van Rossum)이 만든 언어로, 이름은 코미디 쇼 'Monty Python's Flying Circus'에서 따왔어요. 핵심 철학: 사람이 읽기 좋은 코드.

특징 4가지

인간친화적 · 개발 효율(짧은 코드) · 구조적 안정성 · 광범위한 활용(AI·데이터)

버전 역사

0.9.0(1991) → 2.0(2000, 모듈) → 3.0(2008) → 2.x 지원 종료(2020)

실행 방식

파이썬은 인터프리터 언어 — 한 줄씩 해석·즉시 실행

3강 · 데이터 타입, 변수, 연산자

변수는 "값을 담는 이름표 붙은 상자"입니다. =는 수학의 '같다'가 아니라 "오른쪽 값을 왼쪽 상자에 저장하라(할당)"는 뜻이에요.

가장 유명한 첫 프로그램부터 직접 실행해 보세요:

print("Hello World!")
print("파이썬 시작!")
  • 데이터 타입 3총사 — int(정수: 10), float(실수: 3.14), str(문자열: "hello"). "123"은 따옴표가 있으니 숫자가 아니라 문자열!
  • 식별자 규칙 — 변수 이름엔 예약어(if, for, while…)를 쓸 수 없고, 숫자로 시작할 수 없습니다.
  • 연산자 우선순위 — 괄호() → 거듭제곱** → 곱÷나눗셈(* / // %) → 덧뺄셈(+ -) → 비교(< == !=) → not → and → or.
name = "Python"
age = 34          # 1991년생
print(name, "은(는)", age, "살")

x = 2 * (7 + 15)
y = 2 / 10 * 5
z = "computer" + " " + "science"
print(x)
print(y)
print(z)

num_str = "123"          # 따옴표 → 문자열
num_int = int(num_str)   # 정수로 변환
num_float = float(num_str)
print(num_int, num_float)
print(type(num_str), type(num_int))
함정 — input()이 돌려주는 값은 항상 문자열입니다. 숫자로 계산하려면 int()나 float()로 꼭 변환하세요. 시험 단골!
②

제어 구조 — 순차·선택·반복 (4~6강)

구조적 프로그래밍의 3대 구조: 순차(위에서 아래로) · 선택(if로 갈림길) · 반복(while/for로 되풀이). 모든 프로그램은 이 셋의 조합입니다.

4강 · 순차 구조

print("*")
print("***")
print("*****")
print("*******")
  • 프로그램 오류 3종 — 구문 오류(문법 틀림, 실행 전 발견) / 런타임 오류(실행 중 죽음, 0으로 나누기) / 의미 오류(돌아가긴 하는데 결과가 틀림 — 가장 찾기 어려움).
import math

r = 10   # 반지름
h = 24   # 높이

volume = (1/3) * math.pi * r * r * h
print("원뿔의 부피:", volume)

5강 · 선택 구조와 논리 연산자

if 조건: 뒤에 오는 들여쓰기된 블록이 조건이 참일 때만 실행됩니다. 파이썬은 들여쓰기가 문법이에요(보통 스페이스 4칸).

score = 75

if score >= 60:
    print("합격입니다!")
else:
    print("불합격입니다.")

score = 85

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
elif score >= 70:
    print("C학점")
else:
    print("F학점")
  • 비교 연산자 6가지 — < <= > >= == !=. "같다"는 ==(두 개!), =는 할당.
  • 논리 연산자 — and(둘 다 참) / or(하나라도 참) / not(뒤집기).
  • 단락 평가 — and는 앞이 거짓이면 뒤를 보지도 않고, or는 앞이 참이면 뒤를 건너뜁니다(효율↑).
age = 25
income = 3000

print(age >= 20 and income >= 2000)   # 둘 다 참 → True
print(age < 20 or income >= 2000)     # 하나 참 → True
print(not (age >= 20))                # 참을 뒤집음 → False

if age >= 20 and income >= 2000:
    print("대출 가능합니다.")

a, b, c = 17, 42, 29

if a >= b and a >= c:
    print("가장 큰 수:", a)
elif b >= a and b >= c:
    print("가장 큰 수:", b)
else:
    print("가장 큰 수:", c)

6강 · 반복 구조와 리스트

반복은 두 가지: while(조건이 참인 동안 — 횟수 모를 때), for(시퀀스를 하나씩 — 횟수·대상이 정해졌을 때).

n = 10
total = 0
i = 1

while i <= n:
    total += i      # total = total + i 와 같음 (증감 할당)
    i += 1

print("1부터", n, "까지의 합:", total)

hei_list = [1, 4, 14, 26, 31]

for hei in hei_list:
    print(hei)

dan = 7

for i in range(1, 10):
    print(dan, "x", i, "=", dan * i)
  • 리스트 — 여러 값을 순서대로 담는 상자: [1, 4, 14]. 인덱스는 0부터 시작!
  • 증감 할당 연산자 — +=, -=, *=, /=, //=, %=, **=. count += 1은 count = count + 1.
  • range(1, 10) — 1부터 9까지(끝 숫자는 미포함). 함정 단골!
③

함수와 컬렉션 (7~9강)

7강 · 함수

함수는 "이름 붙인 작업 묶음"입니다. 같은 코드를 복사·붙여넣기하는 대신 함수로 만들어 재사용해요. def로 정의하고, 이름+괄호로 호출합니다.

def greet():
    print("안녕하세요!")
    print("파이썬 함수입니다.")

greet()   # 호출 — 이 줄이 없으면 아무 일도 안 일어나요
greet()

def cone_volume(r, h):           # r, h는 매개변수
    vol = (1/3) * 3.14 * r ** 2 * h
    return vol                   # 결과를 돌려준다

v1 = cone_volume(10, 20)         # 10, 20은 인자
v2 = cone_volume(5, 50)
print("원뿔1:", v1)
print("원뿔2:", v2)
  • 내장함수 vs 사용자 정의 함수 — print·input·max·int는 파이썬이 미리 만든 것, def로 만드는 건 사용자 정의.
  • 반환값 유무 — print()는 화면에 보여주기만(반환 없음), input()·max()는 값을 돌려줌(반환 있음).
  • format() — format(3.141592, ">10.3f") = 전체 10자리 오른쪽 정렬, 소수점 3자리 → " 3.142".

8강 · 컬렉션 1 — 리스트 다루기

컬렉션은 데이터 묶음의 총칭: 시퀀스(순서 O: 리스트·튜플) / 비시퀀스(순서 X: 세트) / 매핑(키-값: 딕셔너리). 리스트는 뮤터블(수정 가능)이라 추가·삭제·변경이 자유롭습니다.

body = [181, 78, "dark brown", "black"]

print(body[0])      # 첫 원소 (인덱스 0!)
print(body[2])

body.append(2026)   # 끝에 추가
print(body)
print("원소 개수:", len(body))

9강 · 컬렉션 2 — 튜플·세트·딕셔너리

rad = (7, 22, 4, 22, 47)

print(rad[0])
# rad.append(30)  ← 튜플엔 append가 없어요! 주석을 풀어 실행해 보세요
rad = rad + (30,)   # 대신 + 로 '새 튜플'을 만들 수는 있음
print(rad)

rad_list = [7, 22, 4, 22, 47]

unique = set(rad_list)                          # 중복 22가 하나로!
print(unique)

even = {x for x in rad_list if x % 2 == 0}      # 세트 컴프리헨션
print("짝수만:", even)

student = {"이름": "홍길동", "나이": 25, "전공": "컴퓨터과학"}

print(student["이름"])     # 키로 접근
student["학년"] = 3        # 새 키-값 추가
print(student)

④

클래스 · 모듈 · 파일 (10~12강)

10강 · 객체지향 — 클래스와 인스턴스

클래스 = 설계도, 인스턴스 = 그 설계도로 찍어낸 실물. 객체는 데이터(필드)와 동작(메소드)을 한 단위로 묶은 것(캡슐화)입니다. 붕어빵 틀(클래스)과 붕어빵(인스턴스)으로 기억하세요.

class Cone:
    def __init__(self, radius=20, height=30):   # 생성자(초기자)
        self.r = radius
        self.h = height

    def get_vol(self):                            # 메소드
        return (1/3) * 3.14 * self.r ** 2 * self.h

small = Cone(5, 10)      # 인스턴스 1
big = Cone(20, 30)       # 인스턴스 2 — 같은 틀, 다른 값

print("작은 원뿔:", small.get_vol())
print("큰 원뿔:", big.get_vol())
  • __init__ — 인스턴스가 만들어질 때 자동 호출되는 생성자. self는 "자기 자신".
  • UML 다이어그램 — 클래스를 [이름 / 데이터 필드 / 생성자 / 메소드]로 표준화해 그린 설계도.

11강 · 모듈 — 남이 만든 코드 가져다 쓰기

모듈은 함수·클래스·상수를 모아 둔 .py 파일, 패키지는 모듈을 모은 폴더, 라이브러리는 그 전체 집합. import로 가져옵니다.

import math

print("원주율:", math.pi)
print("최대공약수:", math.gcd(6, 8))
print("제곱근:", math.sqrt(16))
print("올림:", math.ceil(3.2), "/ 내림:", math.floor(3.8))

import random

options = ["가위", "바위", "보"]
user = "바위"                      # 내 선택 (바꿔보세요)
com = random.choice(options)       # 컴퓨터는 랜덤

print("나:", user, "/ 컴퓨터:", com)
if user == com:
    print("비겼습니다!")
elif (user == "바위" and com == "가위") or \
     (user == "가위" and com == "보") or \
     (user == "보" and com == "바위"):
    print("이겼습니다!")
else:
    print("졌습니다!")

import time

start = time.time()

primes = []
for num in range(2, 2000):
    is_prime = True
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            is_prime = False
            break
    if is_prime:
        primes.append(num)

end = time.time()
print("2~2000 사이 소수:", len(primes), "개")
print("걸린 시간:", round(end - start, 4), "초")
  • import 3가지 방법 — ① import math(math.pi로 사용) ② from math import pi(pi로 바로) ③ from math import *(전부 — 이름 충돌 위험).
  • 네임스페이스 탐색 순서 — 지역 → 전역 → 빌트인. 함수 안에서 이름을 찾을 때 이 순서로 뒤집니다.
  • random 함수 구분 — randint(a,b) a~b 정수 / choice(목록) 하나 뽑기 / sample(목록, n) n개 뽑기 / shuffle(목록) 섞기.

12강 · 파일 처리

RAM은 전원이 꺼지면 다 사라지므로(휘발성), 데이터를 남기려면 파일로 저장해야 합니다(영속성). 파일 입출력은 무조건 3단계: open → access(읽기/쓰기) → close.

# ① 쓰기 모드("w")로 열기
fp = open("knou.txt", "w")
fp.write("KNOU\n")
fp.write("python programming\n")
fp.close()                    # ③ 닫기 (무결성·자원 반환)

# 추가 모드("a")로 덧붙이기
fp = open("knou.txt", "a")
fp.write("by CS\n")
fp.close()

# 읽기 모드("r")로 확인
fp = open("knou.txt", "r")
print(fp.read())
fp.close()
  • 모드 3가지 — "r" 읽기 / "w" 새로 쓰기(기존 내용 삭제!) / "a" 끝에 추가.
  • 읽기 메소드 — read() 전체를 문자열로 / readline() 한 줄 / readlines() 전체를 줄 단위 리스트로.
  • 경로 — 절대 경로(루트부터: /var/etc/a.py) vs 상대 경로(현재 기준: ../etc/a.py).
  • 인코딩 — 한글은 UTF-8(국제 표준) 권장. EUC-KR(CP949)은 호환성 문제.
  • strip() — 읽은 줄 끝의 개행(\n)·공백 제거. 비교 연산 오류의 주범 제거!
⑤

프로젝트 — 데이터 분석과 게임 (13~15강)

13강 · 프로젝트 개요 — 데이터 분석 파이프라인

셜록 홈즈 전집(65만 단어!) 같은 텍스트에서 의미를 뽑는 과정은 4단계 파이프라인으로 정리됩니다.

① Collection 수집 ② Preprocessing 전처리 ③ Analysis 분석 ④ Visualization 시각화

전처리가 왜 중요할까? — 원본(Raw Data)에는 형식 불일치·누락·중복이 섞여 있어요. 정제하지 않으면 분석 결과가 왜곡됩니다(쓰레기 입력 → 쓰레기 출력).

14강 · 프로그램 개발 — SDLC와 게임 설계

  • SDLC 6단계 — 계획 → 분석 → 설계 → 구현 → 테스트 → 배포/유지보수. 순서 문제로 출제!
  • 이벤트 기반 프로그래밍 — 버튼 클릭·키 입력 같은 이벤트가 발생하면 이벤트 핸들러가 처리. 게임은 "이벤트 확인 → 로직 실행 → 화면 갱신"을 도는 게임 루프.
  • 틱택토 설계 3분할 — ① 게임판 표현(3×3 리스트) ② 게임 진행(입력·AI·갱신) ③ 승리 판정(가로·세로·대각선).

15강 · 2차원 리스트 — 게임판 만들기

2차원 리스트는 리스트 안의 리스트 — 표(행×열)를 표현합니다. 접근은 board[행][열] 순서!

board = [[1, 2, 3],
         [4, 5, 6],
         [7, 8, 9]]

print(board[0][1])   # 0행 1열 → 2
print(board[2][0])   # 2행 0열 → 7

for row in board:
    print(row)

n = 4
board = [[0] * n for _ in range(n)]   # n×n을 0으로 채워 생성

board[1][2] = 9                       # 1행 2열만 바꾸기

for i in range(n):           # i = 행
    for j in range(n):       # j = 열
        print(board[i][j], end=" ")
    print()

board = [[" " for _ in range(3)] for _ in range(3)]

board[1][1] = "O"    # 가운데에 O
board[0][2] = "X"    # 0행 2열에 X

for row in board:
    print(" | ".join(row))
    print("---------")

② 헷갈리는 짝

        

          
= vs ==
= 할당(저장) / == 같은지 비교

          
int vs float vs str
10 / 3.14 / "123"(따옴표면 무조건 문자열)

          
리스트 vs 튜플
[ ] 수정 가능 / ( ) 수정 불가(append 없음)

          
세트 vs 딕셔너리
{값들} 중복 제거·순서 X / {키: 값} 키로 접근

          
while vs for
조건 반복(횟수 미정) / 시퀀스 순회(대상 정해짐)

          
구문 vs 의미 오류
문법 틀림(실행 불가) / 실행되지만 결과 틀림

          
read vs readlines
전체 문자열 하나 / 줄 단위 리스트

          
"w" vs "a"
새로 쓰기(기존 삭제!) / 끝에 추가

          
choice vs sample
1개 뽑기 / n개 뽑기 (random 모듈)

          
클래스 vs 인스턴스
설계도(붕어빵 틀) / 실물(붕어빵)

          
매개변수 vs 인자
def f(r, h)의 r·h / 호출 f(10, 20)의 10·20

          
모듈 vs 패키지
.py 파일 하나 / 모듈을 모은 폴더
