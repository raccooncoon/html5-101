# HTML5 & CSS 101 — 빠른 학습 노트

HTML5와 CSS를 빠르게 학습하는 한국어 강의 페이지입니다. 강의록 01~09를 정리하고, **시험 정리**와 **인터랙티브 퀴즈(12문항)**를 제공합니다.

🔗 **배포 주소**: https://raccooncoon.github.io/html5-101/

## 특징

- **바로 확인하는 라이브 예시 23종**: 개념마다 "코드 + 실제 렌더링 결과"를 나란히 보여줍니다(iframe 격리 렌더, 높이 자동 조정).
- **라이브 코드 놀이터**: 코드를 직접 고치면 결과가 실시간 반영. 버튼·카드·가운데정렬·그라데이션 프리셋 제공.
- **쉬운 설명**: 어려운 용어를 풀어 쓰고 비유(HTML=뼈대, CSS=인테리어, 시멘틱=이름표)로 안내합니다.
- **자기 시연(self-demonstrating)**: 페이지 자체가 배운 개념(시멘틱 태그, `position: sticky` 목차, Grid 레이아웃, `line-height` 단위 없는 숫자, `word-break: keep-all`)으로 작성되어 있습니다.
- 다크/라이트 테마 토글, 읽기 진행률 바, 목차 자동 강조
- 12문항 객관식 퀴즈 + 즉시 채점 + 오답 해설
- 의존성 없는 순수 HTML/CSS/JS (빌드 불필요)

## 로컬에서 보기

```bash
# 정적 파일이라 그냥 열어도 되고, 간단한 서버로 띄워도 됩니다
python3 -m http.server 8000
# http://localhost:8000
```

## 파일 구조

```
html5-101/
├─ index.html      # 본문 (시멘틱 마크업)
├─ styles.css      # 스타일 (CSS 변수 기반 테마)
├─ demos.js        # 라이브 예시 23종 + 코드 놀이터 프리셋 데이터
├─ quiz-data.js    # 퀴즈 문항 데이터
├─ script.js       # 테마·진행률·목차·라이브 데모·놀이터·퀴즈 로직
└─ .github/workflows/deploy.yml  # GitHub Pages 자동 배포
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
